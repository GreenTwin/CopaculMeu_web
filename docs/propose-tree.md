# Propose a tree

Proposing a tree is a two-step dialog: confirm the GPS position, then enter the species and the other details.

On a phone (viewport width 767px or less) the dialog is a full-screen sheet. The title stays at the top, the step scrolls, and Cancel / Next (or Back / Submit) stay pinned to the bottom. The long step-one instruction is hidden because the note under the map already explains the one-meter cap. Health, watering, and the measurements each get their own row. The health and watering menus use a centered arrow inset from the edge, and the species field uses the same arrow. The species list stays closed until the search field is tapped, then it opens inside the sheet and scrolls with the form, so the last species and the fields below it stay reachable.

From 768px upward the dialog stays a centered card. The action buttons keep their full labels ("Continue to Tree Details", "Back to GPS Adjuster", "Submit Tree Proposal"). The mini-map keeps its zoom buttons on every width; pinch and drag still work.
